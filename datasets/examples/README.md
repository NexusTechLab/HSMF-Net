# Paired examples

Each cultivar folder contains 200 groups: one camera RGB PNG, one ENVI HDR and one extensionless HSI binary per group. There are 800 pairs and 2,400 sample files in total.

`manifest.json` lists cultivar labels, original split membership, relative filenames, file sizes and SHA-256 checksums. Keep the HDR and binary filenames paired. See `../DATA_LAYOUT.md` for reader and tensor-format details.
