# Training-only normalization statistics

Three original mean/std NPZ caches from the completed current controls are supplied: archived-SPA24 matched controls (25 runs), refitted SPA24 (5 runs), and Uniform24 (5 runs). Each stores 24-element mean/std arrays. index.json links each cache hash, selected-band hash and run identities.

These are the current controls’ statistics, not recovered historical S1–S8 caches. Use the cache matching the recorded arm and ordered band set.
