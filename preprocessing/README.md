# Data processing

- `tools/rgb/`: foreground extraction, cropping, resizing and filename utilities.
- `tools/hsi_toolkit/`: ENVI reading, seed segmentation, spectral processing and export.
- `documentation/pipeline.md`: RGB/HSI input preparation.
- `documentation/spectral_preprocessing.md`: spectral smoothing and band indexing.

Network input readers and transforms are in `src/mobilenet_enterprise/data/`.
