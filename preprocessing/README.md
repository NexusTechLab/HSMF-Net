# Preprocessing

- tools/hsi_toolkit/: original HSI import, segmentation and export application with its own requirements.
- tools/rgb/: original foreground/cropping and resizing scripts.
- documentation/pipeline.md: paired input preparation and augmentation.
- documentation/spectral_preprocessing.md: SG, per-kernel spectral processing and index definitions.
- normalization/: three original current-control statistics caches and index.json mapping runs/bands/hashes.

Current statistics and file examples do not authenticate historical S1–S8 input or normalization provenance. Full data layout is described in datasets/DATA_LAYOUT.md.
