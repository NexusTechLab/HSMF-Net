# ENVI HSI processing toolkit

Desktop tools for ENVI image reading, spectral inspection, kernel segmentation and export.

- `modules/`: image and spectral processing algorithms.
- `services/`: loading, segmentation and export services.
- `ui/`: application interface.
- `utils/`: supporting processing utilities.

Install dependencies from `requirements.txt`. Launch `main.py` from this directory to select and process local data. Input and output locations are chosen in the application.
