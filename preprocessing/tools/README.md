# 原始预处理工具源码

- `hsi_toolkit/`：已有HSI Toolkit源码、界面资源和原requirements，含ENVI读取、分割、排序、SG及导出相关实现；未拷贝build/dist/output/logs或任何数据集。
- `rgb/`：原RGB去背景、裁剪缩放和命名脚本。文件名`rbg_process.py`沿用原项目拼写。

这些是原工具的源码记录，不是认证历史每一帧参数或完整采集链的证明。部分脚本保留原工作路径、交互选择或批处理入口；使用前须检查输入/输出路径并在单独环境安装对应依赖。HSI工具主入口为hsi_toolkit/main.py，本次不启动界面或执行数据导出。白/暗参考的实际文件与采集记录仍需随数据另行提供。

网络输入与缓存实现继续以仓库根目录src/mobilenet_enterprise/data/为准；不另行复制一套改写的科学处理逻辑。完整数据集由作者后续传入。
